# 极速页导航（无服务版本）

访问地址：[jisuye.com](https://jisuye.com)

个人页示例：[jisuye.com/demo](https://jisuye.com/demo)

基于 GitHub Pages 的导航站，无后端。全站开源，可 fork 后自行改样式、部署。

数据有两种来源：

| 模式 | 打开方式 | 数据存在哪 |
| --- | --- | --- |
| 访客 | [jisuye.com](https://jisuye.com) | 浏览器本地（`localStorage`），刷新仍在 |
| 个人页 | `jisuye.com/用户名` 或 `jisuye.com/?用户名` | 该用户 GitHub 仓库 `jisuye-data` 的 `data.json` |

个人页由 `404.html` 把 `/用户名` 转到 `?用户名`。fork 数据仓库时请不要改仓库名。

# 使用说明

## 快捷键

不区分大小写。在输入框、对话框、查找面板打开时，不会触发全局快捷键。

| 快捷键 | 功能 |
| --- | --- |
| `S` | 光标进入顶部搜索框 |
| `F` | 打开链接查找（按名称 / 地址过滤，↑↓ 选择，Enter 打开，Esc 关闭） |
| `E` | 进入编辑模式 |
| `V` | 浏览模式：隐藏 / 显示整页链接（搜索框和底栏仍在）；编辑、密保、快捷键匹配页：返回浏览 |
| `P` | 打开密保 |
| `T` | 打开工具页（新标签） |
| `G` + 快键 | 打开链接上标注的快键；多个匹配时继续输入或点选 |
| `Esc` | 取消搜索 / 查找 / `G` 序列，并退出编辑 |

链接快键在编辑时填写，显示在名称旁的小标签里。

## 搜索

默认 Bing。页面加载时会探测 Google 是否可用，可用则切到 Google。

| 引擎 | 快捷键 |
| --- | --- |
| 必应 | `B` |
| 谷歌 | `G` |
| GitHub | `H` |
| 360 | `3` |
| 雅虎 | `Y` |
| 搜狗 | `S` |
| 百度 | `D` |

搜索框内可用 `@引擎` 临时或切换引擎（先按 `S` 再输入）：

- `java@g` 再 Enter：用谷歌搜 java，并记住为当前引擎
- `java@gl`：仅本次用谷歌（编号后加 `l`）
- `java@d,b,3`：同时打开多个引擎（需允许弹窗）
- 谷歌下 `java a`：手气不错
- `a,b split`：把逗号分隔的词分别搜索

搜索框右侧是附加词，会拼到大部分搜索引擎的查询后面（GitHub 除外）。

## 外观皮肤

底部 **皮肤** 随时可开（访客和个人页都可以）。当前 8 套，写在本地，刷新保留：

经典、午夜、宣纸、极客、看板、分栏、目录、列柜。

搜索框和引擎标签会跟皮肤走；开了「每日壁纸」时，搜索区会单独垫一层对比底，避免字糊进图里。

## 插件

底部 **设置 → 插件设置** 开关，状态记在 Cookie。可拖动、缩放：

- 搜索提示（搜索框联想）
- 天气
- 万年历
- 数字时钟
- 快捷便签
- 倒计时
- 每日壁纸（可调背景遮罩）

## 自定义数据（个人页）

fork 仓库：[jisuye-data](https://github.com/iuv/jisuye-data)

不要改仓库名。完成后打开：

```
https://jisuye.com/你的GitHub用户名
```

## 切换代理

个人页如果拉不到 GitHub 上的 `data.json`，用底部 **github代理** 下拉框换一条（也可自定义，地址以 `/` 结尾）。代理也可能失败，多试几个。

## 添加、编辑链接

数据加载完成后（或访客本地已有数据）按 `E`，个人页也可点底部 **显示/编辑**。

可以：

1. 增、删、改链接（名称、地址、颜色、快键、分类编号）
2. 增、删、改分类；分类上 ↑↓ 调顺序
3. 拖动链接调整组内顺序
4. 眼睛按钮隐藏单条链接（浏览模式不显示）；整页隐藏用 `V`

每条链接右侧是隐藏 / 编辑 / 删除图标。

**注意：**

- 个人页：改动先在当前页，点 **复制&提交** 写入 GitHub 前刷新会丢；有未提交修改时关闭标签页会提示。
- 访客：编辑、导入会立刻写入浏览器本地缓存，刷新还在。登录个人页后以仓库数据为准，不会覆盖写本地缓存。

## 保存数据（个人页）

点底部 **复制&提交**：复制当前数据，并打开对应仓库里 `data.json` 的 GitHub 编辑页。全选文件内容，粘贴后提交。保存后再刷新个人页确认。

## 数据加密（个人页）

`jisuye-data` 是公开仓库。要隐藏链接内容：打开 **设置 → 设置密码**，在对话框里输入密码确定，再 **复制&提交**。之后仓库里是密文，打开个人页需输入同一密码。

- 登录成功后密码存在 Cookie，可免重复输入
- 设置密码时留空直接确定，即清除加密
- 前端 AES，无服务端、不记录密码
- 连续输错约 5 次需刷新再试

## 密保

独立于导航加密。按 `P` 或个人页底部 **密保**，用密保密码解锁。记录以表格编辑（网站、用户名、密码），加密后写在导航数据的 `passList` 里，只在本地解密查看。改完后个人页仍需 **复制&提交** 才会进仓库。

## 导入收藏

**设置 → 导入收藏**，选择浏览器导出的 HTML（Chrome 系、Firefox）。名称默认截到 10 个字符。收藏很多时编辑会略卡，导入后建议整理。

访客导入保存在本地；个人页导入后同样要提交到仓库才永久保存。

## 设置、皮肤与退出

底部 **设置**、**皮肤** 访客也能用。个人页设置里才有 **设置密码**、**退出登录**。

退出登录会清掉 Cookie 里的数据密码并回到主页。

## 语言

底部 `en/中文` 切换中英文，优先用本地记录，否则按浏览器语言。

## 工具页

按 `T` 或打开 [alltool.html](alltool.html)：JSON/XML/CSS/SQL 格式化，SHA1/MD5/DES/AES/Base64，编码转换，UTC 与日期互转等。
